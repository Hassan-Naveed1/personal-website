# Hassan Naveed — Personal Portfolio

A personal portfolio website showcasing my software engineering projects, technical skills, and ongoing development journey.

The website provides an overview of my technical background, practical projects, and progress as I continue developing my skills in software engineering.

## Overview

The portfolio was developed to provide a central place to present my work, demonstrate practical programming experience, and document my continued learning.

## Features

- **Project Showcase** – Displays software engineering and data analysis projects, including descriptions, technologies and relevant links.
- **Live Project Links** – Provides direct access to deployed applications and their GitHub repositories.
- **Development Log** – Documents development activities, learning progress and project updates.
- **Responsive Design** – Provides an accessible browsing experience across different screen sizes.
- **Dynamic Content** – Uses TypeScript to generate project listings and development updates.
- **Navigation** – Provides structured navigation between portfolio sections.

## Local Development

### Prerequisites

- Node.js
- npm

### Setup

Clone the repository:

```bash
git clone https://github.com/Hassan-Naveed1/personal-website.git
```

Navigate into the project:

```bash
cd personal-website
```

Install dependencies:

```bash
npm install
```

Compile the TypeScript:

```bash
npm exec -- tsc -p tsconfig.site.json
```

Open the website locally using your preferred development server or local hosting setup.
